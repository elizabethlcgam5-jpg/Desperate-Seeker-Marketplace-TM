DESPERATELY SEEKING™ — COMPLETE NOTIFICATION & MESSAGING SYSTEM
===============================================================

SECTION 1 — GLOBAL NOTIFICATION SETTINGS (Profile → Settings → Notifications)
-----------------------------------------------------------------------------

Page Title: Notification Settings
Subtitle: Control how you receive alerts and messages.

TOGGLES (each with ON/OFF switch + icon + description):

1. Enable Notifications
   Icon: 🔔
   Description: Turn all notifications on or off.

2. Message Alerts
   Icon: 💬
   Description: Show alerts when you receive a new message.

3. Sound
   Icon: 🔊
   Description: Play a soft “ding” when a new message arrives.

4. Vibration
   Icon: 📳
   Description: Vibrate on new messages (mobile only).

5. Email Notifications
   Icon: ✉️
   Description: Receive an email when someone messages you.

6. Push Notifications
   Icon: 📱
   Description: Enable push notifications for real-time alerts.


SECTION 2 — PER-CONVERSATION SETTINGS (Inside each chat → “⋯” menu)
--------------------------------------------------------------------

OPTIONS:

1. Mute Conversation
   Icon: 🔕
   Behavior: No notifications for this chat only.

2. Unmute Conversation
   Icon: 🔔
   Behavior: Re-enable notifications for this chat.

3. Block User
   Icon: 🚫
   Behavior: Prevent this user from messaging again.

4. Report User
   Icon: ⚠️
   Behavior: Report for scams, harassment, or suspicious activity.

5. Delete Chat
   Icon: 🗑️
   Behavior: Remove conversation from inbox.


SECTION 3 — CHAT HEADER DESIGN
-------------------------------

Header Layout:
- User’s profile picture (circle)
- User’s name (bold)
- Online indicator (green dot)
- “⋯” menu on right side

Muted State:
- Show a small 🔕 icon next to the user’s name


SECTION 4 — MESSAGE SOUND SYSTEM
---------------------------------

Sound File:
- Soft “ding” (Messenger-style)
- Format: .mp3 or .wav
- Volume: low and pleasant

Sound plays ONLY if:
- Global Sound = ON
- Notifications = ON
- Conversation is NOT muted

Sound does NOT play if:
- Sound = OFF
- Conversation is muted
- Notifications are disabled


SECTION 5 — VISUAL INDICATORS FOR NEW MESSAGES
-----------------------------------------------

1. Red badge on the Messages icon
   Example: “Messages (1)”

2. Dot indicator next to unread conversations
   Example: ● next to the chat

3. “New message” banner inside chat list

4. Highlight unread messages inside the conversation
   Example: light blue background

- Notifications turned on

- Conversation unmuted
- User blocked
- User reported
- Chat deleted
